# Traffic Accident Severity Prediction System 🚦

## Overview

This project is a Machine Learning-based Traffic Accident Severity Prediction System developed using Python and multiple classification algorithms.

The goal of the project is to analyze traffic accident datasets and predict accident severity levels based on various accident-related features and conditions.

# Project Workflow

## 1. Dataset Loading

The dataset is loaded dynamically using a file selection dialog.

## 2. Data Preprocessing

* Handling missing values
* Separating categorical and numerical features
* Encoding categorical variables
* Feature transformation

## 3. Model Training

The dataset is split into training and testing sets before training multiple machine learning models.

## 4. Model Evaluation

The models are evaluated using:

* Accuracy score
* Classification report
* Confusion matrix

## 5. Feature Importance Analysis

The Random Forest model is used to analyze the most important features affecting accident severity predictions.

## 6. Model Saving

The best-performing model is saved using Joblib for future deployment and integration into applications.
